# Working on this template

Read README.md, DESIGN.md, THIRD-PARTY.md and TEMPLATE.json before changes. Run `npm start` using Node 22 or newer. No npm install is required. Edit HTML pages, css/styles.css and js/scripts.js; keep new served files in public-files.json. server.mjs owns only local static serving and must keep private files, .git and .lyre inaccessible.

Keep upstream MIT notices. Original SVG artwork is Lyre-authored; remote icons, fonts and libraries keep their own terms. Do not add credentials, telemetry, service calls or a backend as part of a presentation edit. Sample forms must never announce delivery or authentication.

Verify at desktop and narrow phone widths, exercise navigation and forms, check the browser console, and deny requests for private files. Record exact scope and remaining limits in VALIDATION.md.
